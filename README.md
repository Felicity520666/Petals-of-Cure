# Petals of Cure
This is a flower-themed visual novel games created using Ren'py.

## About The Game
In this game, you will be on a mission with the protagonist to awaken flower spirits and collect their petals to save the world from a mysterious darkness. Get ready to lean and explore!

## How to Play
Go to https://felicity666.itch.io/petals-of-cure to play online!
